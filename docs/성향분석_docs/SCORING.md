## 1. 왜 축별인가 — 근거 3개

### ① 축마다 좋은 방향이 다릅니다

| 축 | 좋은 상태 | 왜 |
|---|---|---|
| 계획성 | **달라야 좋다** (보완) | 전원이 계획형이면 착수가 늦고, 전원이 실행형이면 겹치는 일과 빠진 일이 동시에 생긴다 |
| 주도성 | **비선형** | 캡틴 0명도 전원 캡틴도 나쁘다. 2:3 근처가 좋다 |
| 갈등대응 | **같아야 좋다** (유사) | 한쪽은 그 자리에서 짚고 한쪽은 나중에 말하면 문제가 두 경로로 흐른다 |
| 소통 | **같아야 좋다** (유사) | 초기 오해 1순위 |

**이걸 하나의 점수로 합치면 방향이 사라집니다.** 그래서 축별로 다른 함수를 씁니다.

### ② 단일 유사도로 바꾸면 실제로 틀립니다 `[실측]`

가장 좋은 형태의 코사인(축별 부호·가중치를 넣은 계량 코사인)으로 재봤습니다.

```
전원 캡틴  우리: 주도 0.25 · 등급 B · 총점 0.618   |  코사인 −0.071
캡틴 0명   우리: 주도 0.00 · 등급 C · 총점 0.530   |  코사인 −0.071
```

구성원이 전원 동일한 두 팀이라 **쌍 유사도의 어떤 평균으로도 구별되지 않습니다.** "몇 명이 주도하는가"는 집합의 성질이지 쌍의 성질이 아니기 때문입니다.

그리고 4,000팀 표본에서 **코사인 값이 소수점 4자리까지 같은데 등급이 A와 B로 갈리는 팀 쌍이 37건** 나왔습니다 — 코사인은 "어느 축이 무너졌는가"를 표현할 수 없습니다. (상세: `COSINE_OPTION.md` §2)

### ③ 왜 그 점수가 나왔는지 화면에 보입니다

축별로 계산하면 **"소통 축이 0.50이라 마찰이 잡혔습니다"** 라고 말할 수 있습니다. 단일 점수면 "0.86입니다"밖에 못 합니다. 우리는 라벨 데이터가 0건이라 학습 모델을 못 만들고, **설명 가능성이 유일한 자산**입니다.

## 2. STEP 1 — 개인: 리커트 → 축 비율

문항 $i$의 응답 $v_i \in \{1,\dots,5\}$, 방향 $d_i \in \{+1,-1\}$.

$$s_i = \begin{cases} v_i & d_i = +1 \\ 6 - v_i & d_i = -1 \ (\text{역채점}) \end{cases}$$

축 $a$의 문항 집합 $A_a$ (6개):

$$m_a = \frac{1}{6}\sum_{i \in A_a} s_i \in [1,5] \qquad\qquad \boxed{\;r_a = \frac{m_a - 1}{4} \in [0,1]\;}$$

$$b_a = \begin{cases} 1 \ (\text{상위 극 P·L·C·D}) & r_a > 0.60 \\ \text{중립 (null)} & 0.40 \le r_a \le 0.60 \\ 0 \ (\text{하위 극 A·S·H·I}) & r_a < 0.40 \end{cases}$$

> $r_a$가 **모든 계산의 입력**입니다. $b_a$는 화면 라벨과 중립 판정에만 씁니다.

### 실제 예 — 지훈의 계획성

```
원응답      [5, 4, 5, 2, 1, 2]      ← P4·P5·P6이 역채점
역채점 후    [5, 4, 5, 4, 5, 4]      ← 6−2=4, 6−1=5, 6−2=4
m = 4.50    r = (4.50−1)/4 = 0.875  →  0.875 > 0.60  →  P
```

## 3. STEP 2 — 팀: 축별 점수 $S_a$

$n$명의 축 비율 $r^{(1)},\dots,r^{(n)}$. **중립인 사람은 축에 따라 다르게 처리합니다.**

### 3.1 계획성 — 보완축

중립 제외한 값들의 폭:

$$\text{spread} = \max_i r^{(i)} - \min_i r^{(i)} \qquad
S_{\text{plan}} = 0.40 + 0.60 \cdot \min\!\left(1,\ \frac{\text{spread}}{2/3}\right)$$

- 전원이 같은 쪽 → spread 0 → **0.40**
- 양극이 다 있음(이진 기준 0/1이 공존 ≈ spread ≥ 2/3) → **1.00**
- 유효 인원 2명 미만 → **0.40** + 마찰

### 3.2 주도성 — 비선형축

$$\bar{r} = \frac{1}{n}\sum_i r^{(i)} \qquad
S_{\text{drive}} = \begin{cases}
0.00 & \bar{r} = 0 \quad\text{(캡틴 0명 — 게이트)}\\
0.25 & \bar{r} \ge 0.95 \quad\text{(전원 캡틴)}\\
0.45 & 0.60 \le \bar{r} < 0.95\\
1.00 & 0.20 \le \bar{r} \le 0.50\\
0.65 & \text{그 외}
\end{cases}$$

> **평균이 높을수록 좋은 게 아닙니다.** 이 구간 함수가 우리 IP의 핵심이고, 어떤 유사도로도 표현되지 않습니다.

### 3.3 갈등대응 · 소통 — 유사축

중립이 낀 쌍은 제외한 유효 쌍 집합 $P$:

$$\text{gap} = \frac{1}{|P|}\sum_{(i,j)\in P} \bigl|r^{(i)} - r^{(j)}\bigr| \qquad
\boxed{\;S = 1 - \text{gap}\;}$$

$\text{gap} \ge 0.45$ 이면 마찰 규칙이 발화합니다.

> 이진값(0/1)을 넣으면 gap이 **불일치 쌍의 비율**과 정확히 같아집니다 — 즉 이 식은 v1 규칙의 연속 일반화입니다.

### 실제 예 — 5명 팀

```
plan      r = [0.875, 0.125, 0.833, 0.125, 0.833]
          spread = 0.875 − 0.125 = 0.750
          S = 0.40 + 0.60 · min(1, 0.750/0.667) = 1.000

drive     r = [0.875, 0.167, 0.167, 0.417, 0.125]
          r̄ = 0.350  →  0.20 ≤ 0.350 ≤ 0.50  →  S = 1.000

conflict  r = [0.667, 0.708, 0.792, 0.583, 0.833]
          유효 쌍 6개(예린 중립 제외) · gap = 0.097  →  S = 0.903

comms     r = [0.833, 0.833, 0.000, 0.000, 0.833]
          유효 쌍 10개 · gap = 0.500  →  S = 0.500
          gap 0.500 ≥ 0.45  →  🔴 "직설과 완곡이 섞인 조합"
```

## 4. STEP 3 — faultline: 팀이 어떻게 갈라졌는가

축별 점수가 "각 축이 얼마나 좋은가"라면, faultline은 **"갈라짐이 축을 가로질러 겹치는가"** 를 봅니다. 축마다 따로 보면 안 보이는 것입니다.

$X$ = $n \times p$ 행렬 ($p=4$, 원소는 $r$).

**Fau** (Thatcher, Jehn & Zanutto 2003) — 모든 2분할 $g$에 대한 최댓값:

$$\text{SST} = \sum_j \sum_i (x_{ij} - \bar{x}_j)^2 \qquad
\text{SSB}(g) = \sum_j \sum_{k=1}^{2} n_k (\bar{x}_{jk} - \bar{x}_j)^2 \qquad
\text{Fau} = \max_g \frac{\text{SSB}(g)}{\text{SST}}$$

**보정 2개** — 논문 수식만 쓰면 오판하는 두 경우를 잡습니다:

$$\text{breadth} = \frac{|\{j : \operatorname{Var}_j > 0\}|}{p} \qquad
\text{balance} = \frac{\min(n_1, n_2)}{\max(n_1, n_2)} \qquad
\text{adjusted} = \text{Fau} \times \text{breadth}$$

- **breadth** — 한 축만 갈려도 Fau가 1.0이 됩니다. 실제로는 한 축만 다른 건데.
- **balance** — 4:1이면 분열이 아니라 **소외**입니다.

**진단 (위에서부터 먼저 걸리는 것):**

| 조건 | 진단 | 총점 보정 |
|---|---|---|
| Fau < 0.35 | 고르게 섞인 조합 | ×1.00 |
| balance ≤ 0.34 | **한 사람이 겉도는 조합** | **×0.85** |
| breadth ≤ 0.35 | 한 가지만 다른 조합 | ×1.00 |
| adjusted ≥ 0.60 | **두 편으로 갈라진 조합** | **×0.75** |
| 그 외 | 부분적으로 갈린 조합 | ×1.00 |

### 실제 예

```
Fau = 0.457   최적 2분할: [하늘, 예린] | [지훈, 민서, 준호]
breadth = 1.000 · balance = 0.667 · adjusted = 0.457
→ Fau ≥ 0.35, balance > 0.34, breadth > 0.35, adjusted < 0.60
→ "부분적으로 갈린 조합" · 보정 없음
```

## 5. STEP 4 — 팀 총점과 등급

$$T_0 = \sum_a w_a S_a, \qquad w = \{\text{drive } 0.35,\ \text{comms } 0.25,\ \text{conflict } 0.20,\ \text{plan } 0.20\}$$

$$T = T_0 \times c, \qquad c = \begin{cases}0.75 & \text{두 편으로 갈라진 조합}\\ 0.85 & \text{한 사람이 겉도는 조합}\\ 1.00 & \text{그 외}\end{cases}$$

**게이트** — 평균은 낮은 값을 가려버립니다 (Halfhill et al. 2005):

| 조건 | 효과 |
|---|---|
| $S_{\text{drive}} = 0$ | **등급 C 강제** — 아무도 안 정하는 팀은 다른 게 좋아도 안 굴러간다 |
| $\min_a S_a < 0.5$ | **A 불가** (A였으면 B로) |

$$\text{등급} = \begin{cases} A & T \ge 0.70 \\ B & 0.45 \le T < 0.70 \\ C & T < 0.45 \end{cases} \quad\text{(게이트 적용 후)}$$

### 실제 예

```
T₀ = 0.20×1.000 + 0.35×1.000 + 0.20×0.903 + 0.25×0.500 = 0.8556
faultline 보정 없음 → T = 0.856
게이트: min S = 0.500 → 0.5 미만이 아니므로 통과
→ 등급 A "바로 시작해도 되는 조합"   (단, 소통 마찰 1건은 그대로 표시)
```

> **A인데 마찰이 있습니다.** 이게 의도한 동작입니다 — 등급은 "얼마나 손이 덜 가는가"고, 마찰은 "그래도 이건 먼저 얘기하라"입니다.

## 6. STEP 5 — 개인 × 개인 조합 점수

**쌍 수준에서는 주도성도 보완입니다** — 한 명이 끌고 한 명이 받치는 게 좋습니다. 팀 수준의 비선형과 다른 이유는, 비선형은 "몇 명인가"의 문제라 쌍에는 없기 때문입니다.

두 사람 $i,j$, 축 $a$:

$$\text{gap}_a = \bigl|r_a^{(i)} - r_a^{(j)}\bigr| \qquad
\text{fit}_a = \begin{cases}\text{gap}_a & a \in \{\text{plan},\ \text{drive}\}\ \ (\text{보완})\\[2pt] 1 - \text{gap}_a & a \in \{\text{conflict},\ \text{comms}\}\ \ (\text{유사})\end{cases}$$

둘 중 하나라도 중립인 축은 판정에서 빼고 **분모도 같이 줄입니다.** 유효 축 집합을 $V$라 하면:

$$\boxed{\ \text{fit}_{ij} = \frac{\sum_{a \in V} w_a \cdot \text{fit}_a}{\sum_{a \in V} w_a}\ }$$

> 근거: Andrés et al.(2011) — 쌍 단위 지수가 평균보다 우수. `[미검증]`
> 16유형 × 16유형 전수표는 `PAIR_MATRIX.md`(136쌍).

### 실제 예 — 10쌍 전부

| 쌍 | plan | drive | conflict | comms | **fit** |
|---|---|---|---|---|---|
| 하늘–예린 | 0.708 | — | — | 1.000 | **0.870** |
| 지훈–민서 | 0.750 | 0.708 | 0.959 | 1.000 | **0.840** |
| 지훈–준호 | 0.042 | 0.750 | 0.834 | 1.000 | 0.688 |
| 민서–준호 | 0.708 | 0.042 | 0.875 | 1.000 | 0.581 |
| 지훈–하늘 | 0.042 | 0.708 | 0.875 | 0.167 | 0.473 |
| 지훈–예린 | 0.750 | — | — | 0.167 | 0.426 |
| 예린–준호 | 0.708 | — | — | 0.167 | 0.407 |
| 민서–하늘 | 0.708 | 0.000 | 0.916 | 0.167 | 0.367 |
| 하늘–준호 | 0.000 | 0.042 | 0.959 | 0.167 | 0.248 |
| 민서–예린 | 0.000 | — | — | 0.167 | **0.093** |

`—` 는 예린이 주도성·갈등 축에서 중립이라 **판정하지 않은** 자리입니다.

**읽는 법**: 지훈–민서(0.840)는 일하는 방식이 정반대고 말하는 방식이 같아서 높습니다. 하늘–준호(0.248)는 반대로 일하는 방식이 같고 말하는 방식이 어긋납니다. **역할 배치는 여기서 나옵니다** — 낮은 쌍을 같은 작업에 묶지 않습니다.

### ⚠️ 쌍 점수의 평균은 팀 점수가 아닙니다

$$\frac{1}{|P|}\sum_{(i,j)} \text{fit}_{ij} \ \ne\ T$$

주도성 비선형과 faultline과 게이트가 팀 수준에만 걸리기 때문입니다. **두 숫자를 더하거나 비교하지 마세요.**

| 값 | 현재 | 어떻게 정할 것인가 |
|---|---|---|
| 가중치 $w$ | .35 / .25 / .20 / .20 | 역할 배치가 출력이라 주도성을 가장 무겁게. **데이터 근거 없음** |

| 이진 경계 | 0.60 / 0.40 | 중립이 절반 넘으면 재보정. `desirability_check.py`가 신호를 띄움 |
| 마찰 임계 | gap ≥ 0.45 | 발화율을 실제 응답으로 확인 |
| faultline 경계 | 0.35 / 0.34 / 0.35 / 0.60 | `faultline.py` 검증 케이스 5종으로만 맞춤 |
| 보정 계수 | ×0.75 / ×0.85 | 강등 폭의 근거 없음 |

> **이 표를 숨기지 마세요.** 심사위원이 *"그 가중치는 어디서 나왔나요?"* 라고 물으면
> **"팀 판단입니다. 데이터가 없어서 정할 수 없었고, 대신 어떤 값이 판단이고 어떤 값이 근거인지 문서에 갈라뒀습니다"** 가 정답입니다.

## 9. 심사위원 대비

> **"점수를 LLM이 지어낸 거 아닌가요?"**
> 파이썬 함수가 계산합니다. 같은 입력이면 항상 같은 점수고, `trace.py`로 계산 흔적을 전부 출력할 수 있습니다.

> **"왜 하나의 궁합 점수로 안 하셨나요?"**
> 축마다 좋은 방향이 다릅니다. 하나로 합치면 '전원이 주도하는 팀'과 '아무도 안 나서는 팀'이 같은 값이 나옵니다. 실제로 재봤고 코사인으로는 구별이 안 됐습니다.

> **"등급 A인데 마찰이 뜨는 건 모순 아닌가요?"**
> 등급은 '얼마나 손이 덜 가는가'고 마찰은 '그래도 이건 먼저 얘기하라'입니다. 예시 팀이 정확히 그 경우입니다 — 총점 0.856인데 소통 축만 0.50이라 마찰이 잡혔습니다.
