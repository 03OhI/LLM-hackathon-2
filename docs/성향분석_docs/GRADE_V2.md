# 등급 판정 개정 — 총점 경계에서 "맞춰야 할 축 개수"로

> 2026-08-28 확정 · 전수 계산 근거는 `grade_sweep.py` · `four.py` · `weak.py` · `decide.py`
> 대상 코드: `chemistry_v2.py` 의 `GRADE_HIGH` · `GRADE_MID` · `GRADES` · 게이트 블록

## 0. 한 줄

**등급을 총점 경계로 가르지 않고 "맞춰야 할 축이 몇 개인가"로 가른다. 3등급 → 4등급.**
맞춰야 할 축 = **0.5 미만인 축 + 판정하지 못한 축** (+ 두 편으로 갈라졌으면 1). [개정 2026-08-28 · 2절]

---

## 1. 왜 바꾸는가

현행 3등급에서 **한 통에 79.4%가 몰린다**(A 4.9 · B 79.4 · C 15.6). 5팀 중 4팀이 같은 통이면 옆 팀과 결과가 같아 보인다. `COMBINATION_SPACE.md` 의 faultline 59% 쏠림과 같은 종류의 결함이고, 처방도 같다 — **몰린 통을 쪼갠다.**

### 폐기한 대안 2개

| 대안 | 실측 | 폐기 사유 |
|---|---|---|
| 상위 경계를 0.70 → 0.60 으로 내림 | A 4.9% → **7.8%가 천장** | 경계를 0까지 내려도 7.8%에서 막힌다. `min(축) < 0.5` 게이트가 경계와 무관하게 강등하기 때문 (게이트 전 A 4,362개 중 3,595개, 82%를 강등) |
| 게이트 임계를 0.5 → 0.4 로 완화 | A 28.1% | 목표는 달성되지만 게이트 근거(Halfhill et al. 2005 / 노연희·손영우 2012 의 우호성 **최솟값** r=−.26)를 버리게 된다. **등급을 하나 늘리면 게이트를 건드리지 않고 같은 목적을 달성한다** |

## 2. 판정 규칙 (구현 사양)

```
w = 0.5 미만인 축의 개수            (판정된 축 중)
  + 판정하지 못한 축의 개수          ← [개정 2026-08-28]

if 판정하지 못한 축 >= 3:      등급 = None       # 4축 중 3개 이상을 못 봤다
elif S_drive == 0:            등급 = 3          # drive_zero 게이트, 현행 유지
else:
    if faultline_kind == "두 편으로 갈라진 조합":
        w += 1
    등급 = min(w, 3)
```

> **[개정 2026-08-28] 못 본 축도 "맞춰야 할 것"으로 센다.**
> 예전 규칙은 못 본 축이 2개면 등급 자체를 내지 않았다(`MAX_UNJUDGED = 2`). 그런데 실제 응답 22명의
> 전수 26,334팀에서 **진단 불가가 23.9%였고 그중 88%가 "정확히 2개만 못 본" 팀**이었다.
> 게다가 그 88% 중 **81%는 판정된 나머지 두 축이 둘 다 0.5 이상**이었다 — 버릴 이유가 없는 팀을
> 통째로 버리고 있었다. 반대로 그들을 최하 등급으로 보내는 것도 틀렸다(**판정 못 함 ≠ 나쁨**).
> 개수로 세면 둘 다 피한다. 등급 이름이 이미 *"N가지를 맞추고 시작하는 조합"*이라
> **이름과 규칙이 같은 것을 가리킨다** — 못 본 축도 첫 회의에서 맞춰야 할 것이다.
> 파라미터는 늘지 않는다(`MAX_UNJUDGED` 2 → 3 하나만 바뀜).

- **총점(T)은 등급 판정에서 빠진다.** 화면에는 계속 표시하되 등급을 정하지 않는다.
- **faultline 강등 계수 ×0.75 / ×0.85 는 총점에만 남는다.** 등급에는 위 `w += 1` 로만 반영한다.
- `axis_below_half` 게이트는 **없어진다** — 규칙 자체가 그 게이트를 흡수했다.
- `drive_zero` 게이트는 그대로 최하 등급 강제.

## 3. 등급 4개와 실측 분포

5명 팀 15,504개 전수 기준.

| w | 비율 | 총점 범위 | 이름 |
|---|---|---|---|
| 0 | 7.4% | 0.62 ~ 1.00 | 바로 시작해도 되는 조합 |
| 1 | 25.7% | 0.47 ~ 0.88 | 한 가지만 맞추면 되는 조합 |
| 2 | 34.1% | 0.37 ~ 0.76 | 두 가지를 맞추고 시작하는 조합 |
| 3+ | 32.8% | 0.31 ~ 0.61 | 먼저 맞출 게 세 가지 이상인 조합 |

**최대 통 79.4% → 34.1%.**

> ⚠️ 이름 2개가 바뀐다. 확정본은 *"두 가지를 맞추면 되는 조합"* 이 없었고 최하가 *"먼저 얘기할 게 세 가지 있는 조합"* 이었다.
> **"얘기할 게" → "맞출 게" 로 바꾸는 이유**: 코드가 `frictions[:2]` 라 화면에 뜨는 마찰은 **최대 2개**다. 최하 등급에서도 99%가 마찰 2개만 뜬다. 이름의 숫자가 마찰 개수로 읽히면 말과 화면이 어긋난다. 숫자는 **축의 개수**를 가리켜야 한다.

## 4. faultline 처리 — 왜 "두 편으로 갈라진 조합"만 한 칸 내리는가

축 점수가 전부 0.5 이상인데도 팀이 두 편으로 갈라진 조합이 **실재한다**(w=0 팀의 5.3%). 갈라짐이 여러 축에서 같은 경계로 겹치는 경우라 축 점수만 봐서는 안 잡힌다. 그래서 등급에 걸어야 한다.

**"한 사람이 겉도는 조합"은 걸지 않는다.** w=0 팀의 46.1%가 여기 해당해서 최상위가 7.4% → 3.8%로 깎인다. 그리고 이 진단은 이미 마찰 문장으로 강하게 나간다.

> ⚠️ 실제 응답 전수에서 이 판정이 **47.8%로 가장 흔하다.** 화면에는 *"한 구성원만 나머지와 성향이 다른 조합"*
> 이라는 마찰이 뜨는데 등급 이름은 *"바로 시작해도 되는 조합"*일 수 있다. 질문이 들어오면 이렇게 답한다 —
> *"등급은 축 점수만 셉니다. 겉도는 사람은 등급이 아니라 마찰 문장과 액션으로 다룹니다."*

| 처리안 | 0개 | 1개 | 2개 | 3개+ | 최대 통 |
|---|---|---|---|---|---|
| ① faultline 안 걸음 | 7.8% | 29.3% | 38.1% | 24.7% | 38.1% |
| **② 두 편 갈라짐만 (채택)** | **7.4%** | **25.7%** | **34.1%** | **32.8%** | **34.1%** |
| ③ 두 편 + 한 명 겉돎 | 3.8% | 20.5% | 36.3% | 39.4% | 39.4% |

## 5. 이 개정으로 얻는 것

**① 심사 질문이 한 번 덜 온다.**

- 총점 4등급이면 → *"이 등급 어떻게 나왔나요"* → *"총점 0.60을 넘겨서"* → *"0.60은 어디서 나왔죠"* → `[팀 판단]`
- 약한 축 개수면 → *"약한 축이 한 개라서"* → **화면에 이미 떠 있는 축 점수 4개를 가리키면 끝**

**② `[팀 판단]` 파라미터가 줄어든다.** 보고서 §9.2 의 등급 경계 `0.70 / 0.45` 두 값이 사라지고 `0.5` 임계 하나만 남는다. 실제 응답이 모이면 재보정할 값도 세 개가 아니라 하나다.

**③ 최상위 등급의 정의가 점수가 아니라 상태가 된다.** *"약한 축이 하나도 없는 팀."* 실측으로 최상위의 약한 축 보유 팀 0%, 2등급 93%, 3등급 100% — 질적으로 다른 상태다. Halfhill(2005)의 "평균이 낮은 값을 가린다"와 정확히 같은 논리다.

**④ 글자 등급이 필요 없어진다.** 이름 자체가 판정 규칙이므로 A·B·C·S 같은 라벨을 화면에 올릴 이유가 없다. `product-design.md` 의 확정 원칙 *"등급 이름은 평가어가 아니라 행동 지시어로"* 와 자동으로 맞는다.

## 7. 정직한 갭

1. **분포는 16유형 균등분포 + 이진(중립 없음) 가정이다.** 리커트 연속값에서는 축 점수가 0.5 근처에 몰리는 양상이 달라진다. 실제 응답 20건이 아직 없다 — 모이면 **0.5 임계 하나만** 재확인하면 된다.
2. **0.5 임계는 여전히 `[팀 판단]`이다.** 다만 세 개에서 한 개로 줄었다.
3. 최하 등급이 32.8%로 현행 C(15.6%)의 두 배가 된다. "먼저 맞출 게 세 가지 이상"이 3팀 중 1팀에 뜬다 — 문장이 겁주는 톤이면 안 된다. 행동 지시어로 읽히는지 문구를 다시 읽을 것.
4. 총점을 등급에서 뺐으므로, 화면에 총점을 계속 보여줄지 결정 필요. 보여주면 *"총점 0.61인데 왜 3등급이죠"* 가 나온다. **총점을 화면에서 빼고 축 점수 4개만 보이는 쪽을 권장.**

## 9. 주도성 ratio 경계는 정수 규칙으로 바꾼다 (2026-08-28 추가)

`score_drive()` 를 인원수 기반으로 고치면서(`SCORE_DRIVE.md`) 남은 `[팀 판단]` 경계 세 개를
실측으로 다시 봤다. **셋 다 없앨 수 있다.**

**0.20 은 죽은 경계다.** 5명 팀에서 `ratio = cap/eff` 가 가질 수 있는 값은 정수 비율뿐이고,
`cap == 0` 은 이미 별도 분기다. 따라서 `cap ≥ 1` 이면 ratio 가 0.20 밑으로 내려갈 수 없다.

| 판정 인원 | 가능한 ratio |
|---|---|
| 3명 | 0, .33, .67, 1.0 |
| 4명 | 0, .25, .50, .75, 1.0 |
| 5명 | 0, .20, .40, .60, .80, 1.0 |

```
현행                          정수 규칙
ratio >= 0.95 → 0.25         cap == eff        → 0.25   전원이 캡틴
ratio >  0.50 → 0.45         cap >  eff/2      → 0.45   캡틴이 과반
ratio >= 0.20 → 1.00         1 <= cap <= eff/2 → 1.00   이상적
else          → 0.65         (도달 불가 — 삭제)
```

5명 팀에서 가능한 모든 `(cap, eff)` 조합을 대조한 결과 **불일치 0건**이다.
값이 하나도 바뀌지 않으면서 `[팀 판단]` 파라미터 3개가 **0개**가 된다.

*"왜 0.95인가요"* → *"전원이 캡틴일 때입니다"* · *"왜 0.50인가요"* → *"캡틴이 과반일 때입니다"*

## 10. 실측 — 총점 경계와 축 개수를 나란히 재보면 (n=22)

**경계에 서 있는 팀의 비율.** 경계에 선 팀은 응답 한 칸만 달라져도 등급이 바뀐다.

| 경계 ±0.05 안 | |
|---|---|
| 총점 경계 방식 (0.70 / 0.45) | **34.0%** |
| 약한 축 개수 방식 (0.5) | **6.3%** |

축 점수들이 0.5 에서 멀리 떨어져 있기 때문이다. 특히 주도성은 구간함수라
값이 `{0.45, 0.65, 1.00}` 뿐이고 **0.5 임계가 그 빈 곳에 놓여 경계에 아무도 안 선다.**

**그리고 실제 응답에서 총점 경계는 쓸 수 없다.** 총점이 0.6~0.9 에 몰려
`0.45 미만` 이 0.1% 다 — 3등급 중 하나가 사실상 안 쓰인다.

### 남는 약점 — 가중치

축 개수 방식은 네 축을 같은 무게로 센다. `주도 .35 / 소통 .25 / 갈등 .20 / 계획 .20` 이
등급에서 사라진다. 실측에서 **계획성이 약한 축인 팀 19.1% · 주도성 0.2%** 라
가장 가벼운 축이 등급을 거의 혼자 결정한다.

다만 지금 데이터로는 가중치를 넣어도 등급이 거의 안 바뀐다(주도성이 약한 팀이 0.2%).
`_similarity` · `score_drive` 를 고친 뒤 다시 볼 것. `[미결]`

## 11. 수정 후 등급 분포 (실제 응답 n=22 · 26,334팀)

실제 응답 22명으로 만들 수 있는 5명 팀을 **전부** 계산했다 — `22C5 = 26,334팀`.
무작위 추출이 아니라 전수라 시드도 반복 횟수도 없다. (무작위 200회×100팀도 같은 67.7%가 나왔다)

| 등급 | 중립대 .40~.60 | 중립대 .45~.55 | **+ 못 본 축 반영 (현행)** |
|---|---|---|---|
| 바로 시작해도 되는 조합 | 15.5% | 36.6% | **12.3%** |
| 한 가지만 맞추면 되는 조합 | 6.0% | 18.0% | **30.0%** |
| 두 가지를 맞추고 시작하는 조합 | 1.5% | 4.5% | **27.7%** |
| 먼저 맞출 게 세 가지 이상인 조합 | 9.4% | 17.1% | **27.2%** |
| **응답 부족 — 진단하지 않음** | **67.7%** | 23.9% | **2.8%** |

- **진단 불가 67.7% → 2.8%.** 두 번의 개정이 각각 절반씩 기여했다 — 중립대 축소(4.4절)가 67.7→23.9,
  못 본 축을 등급에 반영한 이번 개정이 23.9→2.8
- **최대 통 30.0%.** 1·2·3 등급이 30/28/27 로 고르게 갈라진다
- **최상위 12.3% 의 의미가 정확해졌다.** 이전 36.6% 에는 *"축 하나를 못 봤는데도 최상"* 이 섞여 있었다
  (전체 팀의 **47.7%가 축 1개를 못 본 채** 등급을 받고 있었다)
- **남은 진단 불가 2.8%** 는 4축 중 3개 이상을 못 본 팀이다. 여기는 등급을 내지 않는 것이 맞다
- **근본 원인은 그대로다.** 22명 중 네 축이 다 뚜렷한 사람은 **3명뿐**이고, 갈등대응은 여전히 50%가
  판정 불가다. 문항 결함이라 경계로는 못 고친다 (`ALPHA_RESULT.md`)
