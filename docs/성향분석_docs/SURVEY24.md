## 0. v1에서 바뀐 것 2개

| | v1 (양자택일) | **v2 (5점 리커트)** |
|---|---|---|
| 형식 | A/B 중 하나 고르기 | 진술문 하나에 **매우 그렇다 ~ 매우 아니다** |
| 축 점수 | 6문항 중 몇 개 → 0/1 + 중립 | **6문항 평균 1~5 → 비율 0~1** |
| 역채점 | 없음(형식상 불필요) | **축마다 3문항 필수** |
| 사회적 바람직성 | 형식이 구조적으로 막음 | **약해짐 → 문항 균형과 역채점으로 대응** |
| 정보 해상도 | 4:2와 6:0이 같은 값 | **다른 값. 정보 손실 없음** |

### 왜 바꿨나

1. **IPIP 원형이 5점 리커트입니다.** 퍼블릭 도메인 척도의 형식에 맞추면 *"문항 근거가 있냐"*에 답하기 쉬워집니다.
2. **정보 손실이 사라집니다.** v1은 `4:2`와 `6:0`을 같은 `1`로 뭉갰습니다(`RETRIEVAL.md` §11). 리커트 평균은 그 차이를 그대로 담습니다.
3. **중립이 자연스러워집니다.** `3:3`이라는 인위적 조건 대신 평균이 3점 근처면 중립입니다.

### 대신 잃은 것 — 정직하게

**강제선택은 사회적 바람직성 통제에 유리한 형식이었습니다.** 리커트에서는 좋아 보이는 진술문에 전부 '매우 그렇다'를 찍을 수 있습니다.
**대응 3가지**: ① 축마다 역채점 3문항 ② 두 극의 진술문을 똑같이 유능해 보이게 작성(`ITEM_BIAS.md` §2) ③ `desirability_check.py`가 묵종 지수와 문항 쏠림을 잽니다.

> ✅ **역채점이 작동하는지 실측했습니다.** 역채점을 무시하고 전 문항에 4~5를 찍는 묵종 응답자를 넣으니
> 묵종 지수 **4.62**, 그리고 **네 축이 전부 중립**으로 떨어졌습니다.
> **묵종하는 사람은 판정되지 않습니다** — 이게 리커트로 가면서 잃은 방어를 되찾는 지점입니다.

## 2. 계획성 P/A — Big Five 성실성 (order · deliberation)

**P(먼저 그리는 쪽) 높음 / A(먼저 움직이는 쪽) 낮음**

| # | 문항 | 채점 | facet |
|---|---|---|---|
| **P1** | 새 일을 받으면 **전체 순서를 먼저 그린 다음** 착수한다 | **+** | order — 착수 |
| **P2** | 마감이 다가오면 **남은 일을 쪼개 하루치로 나눈다** | **+** | self-discipline — 마감 |
| **P3** | 발표 자료를 만들 때 **목차를 먼저 짜고 칸을 채운다** | **+** | order — 산출물 구조화 |
| **P4** | 일정이 틀어지면 **지금 할 수 있는 것부터 처리하며 계획을 갱신한다** | **−** | deliberation — 변경 대응 |
| **P5** | **되돌릴 수 있는 결정이면 먼저 정하고** 확인은 나중에 한다 | **−** | deliberation — 사전 검토 |
| **P6** | 작업시에 규칙은 **실제로 불편해진 시점에** 만든다 | **−** | order — 협업 절차 |

## 3. 주도성 L/S — Agency (dominance · control)

**L(먼저 정하는 쪽) 높음 / S(받쳐주는 쪽) 낮음**
> Agency = *"dominance, power, status, and control"* (Gurtman, 2009)
> = TKI assertiveness = *"the extent to which one tries to satisfy **his or her own** concerns"*

| # | 문항 | 채점 | facet |
|---|---|---|---|
| **L1** | 회의에서 방향이 안 잡히면 **내가 안을 내놓는다** | **+** | 발의 |
| **L2** | 역할을 나눌 때 **하고 싶은 역할을 먼저 말한다** | **+** | 역할 선점 |
| **L3** | 내 안이 밀려도 **한 번 더 설득해본다** | **+** | **관철 (핵심 assertiveness)** |
| **L4** | 의견이 반반으로 갈리면 **정해지는 대로 따르는 편이다** | **−** | 결정 주도 |
| **L5** | 일이 몰려도 **일단 내 선에서 처리해본다** | **−** | 자원 요구 |
| **L6** | 팀 결과 전체보다 **맡은 부분을 확실히 하는 게 편하다** | **−** | 책임 귀속 |

## 4. 갈등대응 C/H — Communion (cooperativeness)

**C(바로 말하는 쪽) 높음 / H(고르게 만드는 쪽) 낮음**
> Communion = *"love, affiliation, union, and friendliness"* (Gurtman, 2009)
> = TKI cooperativeness = *"the extent to which one tries to satisfy the concerns of **another person**"*

| # | 문항 | 채점 | facet |
|---|---|---|---|
| **C1** | 팀원 결과물이 아쉬우면 **그 자리에서 짚는다** | **+** | 제기 시점 |
| **C2** | 작업에서 실수가 나오면 **원인을 바로 짚는다** | **+** | 실수 대응 |
| **C3** | 같은 문제가 또 생기면 **규칙을 바꾸자고 공식적으로 제기한다** | **+** | 반복 문제 |
| **C4** | 의견이 갈리면 **접점을 찾아 좁히는 편이다** | **−** | 이견 조율 |
| **C5** | 팀원 둘이 부딪히면 **감정이 상하지 않게 사이를 조율한다** | **−** | 제3자 충돌 |
| **C6** | 내 방식과 팀 방식이 다르면 **팀 방식을 따르고 필요하면 나중에 제안한다** | **−** | 양보 |

## 5. 소통 직접성 D/I — `[팀 판단 축 · 문헌 근거 없음]`

**D(결론부터 쪽) 높음 / I(배경부터 쪽) 낮음**

> ⚠️ **이 축만 확립된 척도에 대응하지 않습니다.** 팀이 현장 관찰로 추가했습니다. **"이 축도 문헌 근거가 있다"고 말하지 마세요.**
> 설계 제약: **"말하느냐 마느냐"는 C축입니다. 이 축은 "어떻게 말하느냐"만 묻습니다.**

| # | 문항 | 채점 | facet |
|---|---|---|---|
| **D1** | 문제를 알릴 때 **결론부터 말한다** | **+** | 전달 순서 |
| **D2** | 요청을 못 받을 때 **안 된다고 명확히 말한다** | **+** | 거절 |
| **D3** | 고칠 점을 **그대로 짚어 오해를 줄인다** | **+** | 표현 강도 |
| **D4** | 내 의견이 다수와 다르면 **분위기를 보며 조심스럽게 꺼낸다** | **−** | 이견 표명 |
| **D5** | 메신저로 의견을 전할 때 **완충 표현을 더해 부드럽게 적는다** | **−** | 문체 |
| **D6** | 도움이 필요할 때 **상대 상황을 살피며 에둘러 꺼낸다** | **−** | 요청 방식 |

## 6. 채점 규칙 (`likert.py`)

```
1) 역채점(−) 문항:  점수 = 6 − 응답
2) 축 원점수      = 6문항 평균 (1.00 ~ 5.00)
3) 축 비율 r      = (평균 − 1) / 4        → 0.00 ~ 1.00
4) 이진 변환      r > 0.60 (평균 3.4 초과) → 상위 극 (P·L·C·D)
                  r < 0.40 (평균 2.6 미만) → 하위 극 (A·S·H·I)
                  그 사이                  → 중립 (null)
```

**`r`이 그대로 `chemistry_v2.py`의 축 비율입니다.** v1의 `confidence`("5:1") 변환이 필요 없어집니다 — 리커트가 처음부터 연속값을 줍니다.

### 화면 표시

| 조건 | 표시 |
|---|---|
| 평균 ≥ 4.0 또는 ≤ 2.0 | 표시 없음 (뚜렷함) |
| 그 사이, 중립 아님 | *"계획성은 먼저 그리는 쪽입니다 (평균 3.7 / 5점)"* |
| **중립** | *"이 축은 뚜렷하지 않습니다 (평균 3.1)"* + **마찰 규칙 트리거에서 제외** |
| **표준편차 ≥ 1.2** | *"응답이 문항마다 갈렸습니다"* — 축 안에서 일관되지 않음 |

**확신의 정도를 그대로 보이는 것이 "판정하지 않는다"의 실천입니다.**
