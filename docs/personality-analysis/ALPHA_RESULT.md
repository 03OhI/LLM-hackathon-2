# 내적 일관성 측정 — n=22, 표본을 늘려도 결론이 같다

> 2026-08-28 · 응답 **22건** (17건 + 추가 5건) · 원자료 `responses22.jsonl` · 재현 `alpha_check.py` · `desirability_check.py`
> 보고서 §9.1 의 `[미측정]` 을 채운 기록. **n=22 는 20건 선을 넘었으므로 인용 가능하다.**

## 0. 한 줄

**5건을 더 받았더니 모든 지표가 같은 방향으로 유지됐고, 일부는 더 나빠졌다. 표본 크기 문제가 아니라는 것이 확인됐다.**

## 1. 17건 → 22건, 결론이 흔들리지 않는다

| 지표 | n=17 | **n=22** | |
|---|---|---|---|
| α 계획성 | 0.396 | **0.349** | 유지 |
| α 주도성 | 0.401 | **0.367** | 유지 |
| α 갈등대응 | −0.306 | **−0.501** | 🔴 더 나빠짐 |
| α 소통 | 0.590 | **0.560** | 유지 |
| MIC 계획성 | 0.083 | **0.079** | 사실상 동일 |
| MIC 주도성 | 0.094 | **0.082** | 사실상 동일 |
| MIC 갈등대응 | −0.062 | **−0.074** | 사실상 동일 |
| MIC 소통 | 0.173 | **0.167** | 사실상 동일 |

**평균 문항간 상관(MIC)이 거의 그대로다.** MIC 는 α 보다 표본 크기에 덜 민감한 지표인데, 5건을 더해도 소수 셋째 자리만 움직였다. Clark & Watson(1995) 권장 구간 .15~.50 에 소통(.167)만 겨우 하단에 걸친다.

**갈등대응 α 가 −0.306 → −0.501 로 더 내려갔다.** 표본이 늘면 추정이 안정되는 것이 보통인데 음수가 커졌다는 것은 그 축이 실제로 깨져 있다는 뜻이다.

## 2. 균형 척도 — 여전히 무너져 있다

정방향 3문항 평균 + 역채점 3문항 평균은 **6.0** 이어야 한다.

| 축 | n=17 | **n=22** | 변화 |
|---|---|---|---|
| 계획성 | 7.53 | **7.35** | −0.18 |
| 주도성 | 7.43 | **7.35** | −0.08 |
| 갈등대응 | 8.14 | **7.70** | −0.44 |
| 소통 | 7.43 | **7.27** | −0.16 |

조금 내려갔지만 **네 축 모두 여전히 7.3~7.7 이다.** 6.0 에서 1.3~1.7 만큼 위로 쏠려 있다.

### 아무도 부정하지 않는 문항 — 개수가 같다

| | n=17 ('아니다' 2명 이하) | n=22 ('아니다' 3명 이하) |
|---|---|---|
| 해당 문항 | **11개** | **11개** |
| 그중 역채점 | 5개 | **7개** |

비율 기준을 맞춰 세면 개수가 정확히 같고, **역채점 쪽이 5개에서 7개로 늘었다.** L1("회의에서 방향이 안 잡히면 내가 안을 내놓는다")은 22명 중 **0명**이 부정했다.

| 계획성 | 0.37 🔴 | **0.33** 🔴 | −0.051 |

## 4. 등급 분포도 같은 모양이다

`_similarity` 와 `score_drive` 를 고친 뒤 기준.

| | n=17 (6,188팀) | **n=22 (26,334팀)** |
|---|---|---|
| 바로 시작해도 되는 조합 | 24.7% | 17.3% |
| 한 가지만 맞추면 | 7.3% | 5.4% |
| 두 가지를 맞추고 | 1.1% | 0.7% |
| 세 가지 이상 | 10.2% | 8.9% |
| **응답 부족 — 진단 안 함** | **56.7%** | **67.7%** |

최하 등급은 두 표본 모두 **100%가 "캡틴 0명" 게이트**다. 등급이 나온 팀 중 최상위 비율도 57.1% → 53.4% 로 거의 같다.

**진단 불가가 67.7% 로 늘었다.** 중립 판정이 50% → 53% 로 오른 결과다.

## 5. 원인과 처방은 그대로

원인은 문항이다. 정방향도 역채점도 둘 다 "좋은 사람" 진술이라 응답자가 양쪽에 다 동의한다. 처방은 **문항 안에 포기하는 것을 넣는 것**이다.

| 현재 | 고친 안 |
|---|---|
| 의견이 갈리면 접점을 찾아 좁히는 편이다 | 의견이 갈리면 **결론이 늦어지더라도** 모두가 납득할 선을 찾는다 |
| 회의에서 방향이 안 잡히면 내가 안을 내놓는다 | **다른 사람 얘기를 더 듣기보다** 내가 먼저 안을 낸다 |
| 일정이 틀어지면 지금 할 수 있는 것부터 처리하며 계획을 갱신한다 | **계획을 다시 세우기보다** 지금 할 수 있는 것부터 손댄다 |
| 일이 몰려도 일단 내 선에서 처리해본다 | **도움을 요청하기 전에** 내 선에서 먼저 해본다 |
| 팀원 둘이 부딪히면 감정이 상하지 않게 사이를 조율한다 | **누가 맞는지 가리기보다** 사이를 먼저 푼다 |
| 내 방식과 팀 방식이 다르면 팀 방식을 따르고 나중에 제안한다 | **그 자리에서 말하기보다** 일단 팀 방식을 따른다 |

`[팀 판단]` — 이 방식이 균형을 회복시키는지는 재수집해야 알 수 있다.

## 6. 발표 문장

> "설문을 22명한테 돌렸습니다. **결과가 나빴습니다** — 네 축 모두 α가 .60을 못 넘었고 갈등대응은 −.50 이었습니다.
>
> 처음엔 17명이라 표본 탓인가 했습니다. 그래서 5명을 더 받았습니다. **모든 지표가 그대로였고 갈등대응은 오히려 더 내려갔습니다.** 평균 문항간 상관은 소수 셋째 자리만 움직였습니다.
>
> 원인은 표본이 아니라 문항이었습니다. **정방향 문항과 역채점 문항 평균의 합이 6.0이어야 하는데 7.3에서 7.7이 나왔습니다.** 서로 모순인 두 진술에 응답자들이 둘 다 동의하고 있었습니다. 22명 중 아무도 '아니다'를 고르지 않은 문항이 11개였습니다."

### 말하면 안 되는 것

🔴 **"α가 낮지만 문항이 적어서 그렇습니다"** — MIC 가 .079~.167 이다. 문항 수 문제가 아니고, 늘려도 안 오른다.
🔴 **"표본이 작아서 그렇습니다"** — 17건과 22건이 같은 값을 준다. 이 반박은 데이터로 이미 막혀 있다.
