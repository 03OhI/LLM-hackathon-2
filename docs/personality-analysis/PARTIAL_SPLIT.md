# "부분적으로 갈린 조합" 분할 — 59.0% → 최대 22.0%

> 2026-08-28 · 근거 스크립트 `split59.py` · `newcases.py` · `gimpact.py` · 복붙용 리터럴 `cases_partial_split.py`
> 대상: `faultline.py` 의 `diagnose()` · `cases.py` 의 TEAM_CASES

---

## 0. 한 줄

faultline 진단의 `else` 분기가 전수의 **59.0%** 를 먹고 있었다. **breadth 와 Fau 로 4개로 쪼갠다.** 최대 통은 22.0%(다른 진단)로 내려가고, 등급 규칙은 건드리지 않는다.

---

## 1. 🔴 보고서 §8.2 의 지침을 하나 정정한다 — balance 로는 못 쪼갠다

보고서는 *"breadth와 balance 기준으로 3~4개로 쪼개야 한다"* 고 적었다. 실제로 돌려보니 **balance 는 이 통 안에서 상수다.**

5명 팀의 2분할은 1:4(balance 0.25) 또는 2:3(balance 0.667) 뿐인데, `balance ≤ 0.34` 는 이미 앞 분기인 "한 사람이 겉도는 조합"이 가져간다. 그래서 `else` 로 떨어진 9,146개는 **전부 balance = 0.667** 이다.

| 통 안에서 변하는 값 | 분포 |
|---|---|
| **breadth** (차이가 있는 축의 개수 / 4) | 0.50 → 7.3% · 0.75 → 30.1% · 1.00 → **62.6%** |
| **Fau** (갈라짐의 선명도) | 중앙값 0.537 · 사분위 0.470~0.583 |
| balance | **0.667 하나뿐 (100%)** |

→ 분할 기준은 **breadth 3단계**, 그리고 가장 큰 breadth 1.00 을 **Fau 0.5** 로 한 번 더.

**Fau 0.5 는 임의의 선이 아니다.** `Fau = SSB/SST` 이므로 0.5 는 *"최적 2분할이 전체 분산의 절반 이상을 설명한다"* 는 뜻이다. 경계가 흐릿한 쪽과 겹치기 시작한 쪽이 여기서 갈린다.

```python
# ── 아래 4줄이 신규. 기존 "부분적으로 갈린 조합" 을 대체한다
elif br <= 0.50:      kind = "차이가 두 가지 성향에서만 나타나는 조합"
elif br <= 0.75:      kind = "세 가지 성향에서 차이가 나는 조합"
elif f  <  0.50:      kind = "매번 다른 사람끼리 같은 편이 되는 조합"
else:                 kind = "같은 두 무리가 반복해서 생기는 조합"
```

앞 네 분기는 그대로다. `else` 하나만 넷으로 갈라진다.

## 5. 등급에는 걸지 않는다 (A안 확정)

`PARTIAL_HARDENING`("같은 두 무리가 반복")은 "두 편으로 갈라진 조합"의 전 단계다. GRADE_V2 의 `+1` 을 여기에도 걸지 검토했다.

| | 0개 | 1개 | 2개 | 3개+ | 최대 통 |
|---|---|---|---|---|---|
| **A · 안 걸음 (채택)** | **7.4%** | **25.7%** | **34.1%** | **32.8%** | **34.1%** |
| B · 걸음 | 6.6% | 21.3% | 31.4% | 40.8% | 40.8% |

B안은 전부 나쁜 방향이다 — 최상위가 줄고, 최하가 40.8%로 커지고, 최대 통도 34.1% → 40.8%로 다시 벌어진다. 방금 GRADE_V2 로 34.1%까지 내려놓은 것을 되돌리는 셈이다.

개념적으로도 A가 맞다. `PARTIAL_HARDENING` 은 *"아직 안 굳었다"* 는 진단인데 등급까지 내리면 진단과 등급이 같은 말을 두 번 한다. **경고는 문단이 하고, 등급은 축 상태만 본다.**

→ **GRADE_V2 를 건드리지 않는다.** 분할은 진단 문장만 바꾼다.

## 7. 남는 결정 2개

1. **새 4건을 마찰 목록에 띄울 것인가.** 현재 faultline 진단은 `TEAM_SPLIT` 과 `TEAM_ISOLATED` 만 `frictions` 에 들어가고 나머지는 `faultline_kind` 필드로만 나간다. `PARTIAL_HARDENING` 은 *"지금 손대면 굳은 뒤보다 싸다"* 는 시점 정보라 마찰로 띄울 값어치가 있다. (`frictions-audit` 의 3번 이슈와 같은 자리)
2. **`TEAM_MIXED` 문단 재작성** — 이번 분할과 별개로 아직 남아 있다. Thatcher(2003)의 *"faultline이 거의 없는 팀도 갈등이 많고 성과가 낮았다"* 를 반영해야 한다. 지금 문단이 "문제 없음"으로 읽히면 논문과 반대가 된다.
