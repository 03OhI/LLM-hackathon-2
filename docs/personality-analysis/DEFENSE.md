> 2026-08-28 · 응답 17건 실측 · `ALPHA_RESULT.md` 후속 · 재수집 불가 확정에 따른 방어선 문서

## 0. α보다 급한 게 나왔다

α가 낮은 것은 문항 문제였다(`ALPHA_RESULT.md`). 그런데 그 문항 문제가 **코드의 한 줄과 만나서 결과를 뒤집고 있었다.**

| | 무작위 15,504팀 | **실제 응답 6,188팀** |
|---|---|---|
| 최상위 등급 | 4.9% | **60.8%** |
| 마찰 0건 (화면이 빈다) | — | **19.4%** |
| "주도적인 구성원이 다수인 조합" 발화 | 43.5% | **0.0%** |

무작위 시뮬레이션에서 A가 4.9%라 "너무 짜다"고 걱정했는데, **실제 응답에서는 60.8%가 최상위**다.

---

## 1. 원인 — `_similarity()` 가 판정 불가에 만점을 준다

```python
def _similarity(rs, neutral):
    pairs = [(i, j) for i, j in combinations(...)
             if not neutral[i] and not neutral[j]]
    if not pairs:
        return 1.0, 0.0        # ← 판정할 쌍이 하나도 없는데 만점
    gap = sum(abs(rs[i] - rs[j]) for i, j in pairs) / len(pairs)
    return 1.0 - gap, gap
```

5명 팀의 쌍은 10개다. 중립이 3명이면 유효 쌍 1개, 4명이면 0개가 된다.

**실제 응답에서:**

| 유효 쌍 | 갈등대응 | 소통 | |
|---|---|---|---|
| **0개** | **39.5%** | **11.1%** | 🔴 판정 불가인데 축 점수 1.00 |
| 1개 | 40.0% | 32.6% | 🟡 단 한 쌍으로 축을 판정 |
| 3개 이상 | 20.6% | 56.3% | |

**유사축 판정의 25.3%가 유효 쌍 0개로 만점을 받았고, 89.5%가 쌍 3개 이하로 결정됐다.**

### 인과 사슬

```
문항이 정방향·역방향 둘 다 바람직        (ALPHA_RESULT §2)
  → 응답이 4~5점에 몰림                  (전체 평균 3.82)
  → 역채점 후 축 비율 r 이 0.5 근처로 뭉침 (폭 0.38~0.58, 이론상 1.00)
  → 중립 판정 50%                        (68개 축 판정 중 34건)
  → 유사축 유효 쌍이 0~1개
  → if not pairs: return 1.0             ← 여기서 뒤집힌다
  → 축 점수 0.96~1.00
  → 약한 축이 없으니 최상위 등급 60.8%
  → 마찰이 안 걸려 19.4%는 화면이 빈다
```

**"판정하지 않는다"는 원칙이 코드에서 "문제 없다"로 번역되고 있었다.** 이건 제품의 핵심 주장과 정반대다.

## 2. 오늘 고칠 수 있다 — 한 곳

```python
MIN_PAIRS = 3          # 5명 팀 10쌍 중 3개. 판정된 사람이 최소 3명이라는 뜻 [팀 판단]

def _similarity(rs, neutral):
    pairs = [...]
    if len(pairs) < MIN_PAIRS:
        return None, None      # 축 점수 없음 — 등급·마찰에서 제외
    ...
```

보완축(계획성·주도성)도 같은 원리로 유효 인원 2명 미만이면 판정하지 않는다. 그리고 **판정 불가 축이 2개 이상이면 등급을 내지 않는다.**

### 고치면 이렇게 된다

| 판정 불가 축 | 비율 | 화면 |
|---|---|---|
| 0개 | 7.7% | 등급을 낸다 |
| 1개 | 53.9% | 등급을 내되 그 축은 "판정하지 않았습니다" |
| 2개 이상 | **38.4%** | **"응답이 부족해 진단하지 않았습니다"** |

**38.4%가 진단 불가로 바뀐다.** 숫자는 나빠 보이지만 그게 사실이고, *"확신이 없으면 판정하지 않는다"* 는 제품 원칙과 처음으로 일치하게 된다.

> ⚠️ `MIN_PAIRS = 3` 은 `[팀 판단]` 이다. "최소 세 명은 판정돼야 그 축을 말할 수 있다"는 기준일 뿐 문헌 근거가 없다.

## 3. 하지 말아야 할 대응 — 중립 경계를 좁히는 것

누군가 *"중립 경계 0.40/0.60을 좁히면 되잖아"* 라고 할 것이다. **된다. 그런데 노이즈를 판정으로 바꾸는 것이다.**

| 경계 | 중립 | 새로 판정된 사람들의 \|r − 0.5\| |
|---|---|---|
| 0.40 / 0.60 (현행) | 34건 | — |
| 0.45 / 0.55 | 25건 | 0.125 |
| 0.48 / 0.52 | 10건 | 0.125 |

0.48/0.52로 좁히면 중립은 거의 사라지지만, 새로 판정되는 사람의 r 은 0.5에서 **0.02~0.05** 떨어져 있다. 6문항 평균으로 0.03 차이를 "성향"이라 부를 수 없다.

**중립이 많은 것은 경계 문제가 아니라 응답이 중앙에 몰린 결과다.** 경계를 건드리면 증상만 가린다.

## 4. 유형 4글자도 오늘 손봐야 한다

17명 중 **네 축이 모두 뚜렷한 사람은 1명(6%)** 이다.

| 뚜렷하지 않은 축 | 인원 |
|---|---|
| 0개 | 1명 (6%) |
| 1개 | 5명 (29%) |
| 2개 | 6명 (35%) |
| 3개 이상 | 5명 (29%) |

그런데 `likert.type_code()` 는 뚜렷하지 않은 축을 **팀 다수 쪽으로 채워서** 4글자를 만든다. 화면에 "당신은 PLCD입니다"가 뜨면 **94%는 채워 넣은 값이 섞인 코드**다.

**이건 MBTI 방어선과 직결된다.** *"개인에게 유형 이름을 주지 않는다"* 고 했는데 실제로는 주고 있고, 게다가 대부분 추측이다.

→ 오늘 할 일: 뚜렷하지 않은 축은 글자 대신 `?` 로 두거나(`PL?D`), 유형 코드를 화면에서 빼고 축 4개만 보여준다.

## 5. 무엇이 살아남고 무엇이 흔들리는가

**흔들리는 것 — 입력**

- 축 비율 r 이 개인의 성향을 안정적으로 재는지 보장할 수 없다 (α .40~.59, 갈등대응 음수)
- 그 위에 쌓인 개인 수준 판정 — 유형, 축 라벨
- *"24문항으로 협업 성향을 잰다"* 는 주장

**살아남는 것 — 엔진**

- **축마다 좋은 방향이 다르다**(보완/유사)는 설계. 문항과 독립이며, 코사인 반례 2건으로 검증됨
- **결정론적 계산과 계산 흔적 출력** — 같은 입력이면 항상 같은 출력
- **전수 계산 15,504팀** — 조합 공간, 등급 경계, faultline 분할
- **케이스↔논문 손매핑**과 근거 표시 게이트
- **RAG를 구현하고 뺀 기록**

**정확한 비유는 "엔진은 돌고 계기판이 아직 안 맞는다"** 이다. 그리고 오늘 찾은 `_similarity()` 결함은 계기판이 아니라 엔진 쪽이었고, 그건 고칠 수 있다.

## 6. 고쳐 쓸 한계 문장 (그대로 붙여넣기)

**보고서 §9.1 표** — `Cronbach's α` 행

> | Cronbach's α (내적 일관성) | **[측정됨 · 미달]** n=17에서 계획성 .40 · 주도성 .40 · 갈등대응 **−.31** · 소통 .59. 평균 문항간 상관 .03~.17로 Clark & Watson(1995) 권장 .15~.50에 못 미친다 | 문항 재작성 후 재측정 |

**보고서 §4.3** — 역채점 방어 논리

> **[검증됨 — 예상과 반대]** 부정어를 쓰지 않은 것이 오히려 원인이었다. 정방향과 역채점이 둘 다 바람직한 진술이라 응답자가 양쪽에 모두 동의했다. 축별 정방향 평균 + 역채점 평균이 6.0이어야 하는데 7.43~8.14가 나왔고, 정방향↔역방향 교차 상관은 음수였다(계획성 −.07, 갈등대응 −.23).

**보고서 §9.4 / SURVEY24 §8** — 새 항목

> **판정 불가에 만점을 주고 있었다.** `_similarity()` 가 유효 쌍이 없을 때 축 점수 1.0을 반환해, 중립이 많은 팀일수록 축 점수가 높아졌다. 실제 응답 기준 유사축 판정의 25.3%가 유효 쌍 0개로 만점을 받았고, 그 결과 최상위 등급이 무작위 4.9% 대비 60.8%로 나왔다. 2026-08-28 실측으로 발견.
